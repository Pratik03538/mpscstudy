# MPSC Study Telegram Bot

Subject-only Telegram MCQ practice bot using the MPSC subject database. It intentionally has no subtopic/topic menu.

## Features
- `/start`, `/subjects`, `/stats`, `/help`
- Four subjects: Economics, Geography, History, Marathi Grammar
- Random 10, 20 or 50 question practice sessions
- A/B/C/D inline answers, stored answer-key feedback, and available Marathi/English explanations
- Per-user progress stored separately in `data/bot_progress.sqlite3`
- Question database opened read-only; user progress never changes the question bank
- Runtime logs saved under `outputs/bot.log`

## Database copy

The distributable project ZIP includes `database/mpsc_subject_only.db`. The binary database is intentionally excluded from GitHub; never commit a database or user-progress file unless you explicitly intend to publish its contents. For a fresh checkout, copy the subject-only database generated by `build_subject_only_db.py` into `telegram_bot/database/mpsc_subject_only.db`.

Current source counts: Economics 1,931; Geography 9,357; History 8,403; Marathi Grammar 5,490; total 25,181. These are source subject assignments. Question-to-subject accuracy and answer-key factual accuracy have not been independently verified; bot feedback presents the stored answer key as source data.

## Windows setup

1. Python 3.10+ recommended.
2. Create a Telegram bot through `@BotFather` and obtain its token.
3. Copy `.env.example` to `.env`, then set `TELEGRAM_BOT_TOKEN`. Never share or commit `.env`.
4. Ensure the database exists at `database/mpsc_subject_only.db`.
5. In PowerShell from this directory run:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python .\bot\bot.py
```

Or run `.\run_bot.ps1` after setting the token. The bot uses long polling, so the process must stay running to receive Telegram updates.


## Telegram connection troubleshooting

If startup reports `telegram.error.TimedOut`, the question database is not the cause. The bot must connect to Telegram over HTTPS at `api.telegram.org:443`. The bot configures 30-second connection/write/read timeouts and retries startup up to five times, but a blocked or unreachable route still needs to be fixed at the network level.

Run this token-free diagnostic from this folder:

```powershell
.\test_telegram_network.ps1
```

A successful DNS lookup, `TcpTestSucceeded : True`, and an HTTP response from `curl.exe` indicate DNS/TCP/TLS connectivity. An HTTP 404/405 at the API root is acceptable for this connectivity test; no bot method or token is being called. A timeout/failure indicates a DNS, ISP/router, firewall/antivirus or required HTTPS-proxy issue. Do not paste your bot token into a diagnostic command or chat.
